Diário do Farol

Site de notícias simples, feito com HTML, CSS e JavaScript puro (sem bibliotecas).

Estrutura

| Arquivo | Função |
|---|---|
| `index.html` | Estrutura da página: topo, menu, busca, área de conteúdo e rodapé |
| `style.css` | Aparência: cores, tipografia, grade de notícias, modo escuro e versão para celular |
| `script.js` | Comportamento: dados das notícias, filtro por seção, busca, página da matéria e troca de tema |

Funcionalidades

- Lista de notícias com a primeira em destaque
- Filtro por seção (Brasil, Economia, Tecnologia, Ciência, Saúde, Esportes)
- Busca por título e resumo
- Página de leitura de cada matéria, com botão de voltar
- Modo claro e escuro
- Layout que se adapta ao celular
